# 0.2.0 — NIKKE 152.8.11 更新适配

针对 NIKKE PC 国际服 152.8.11 的实验性源码更新。测试环境为 Apple M4 Max、macOS 27.0、CrossOver 26.1，使用 DXVK 和原有视频软件回退配置。

## 本次变化

- 移植 DW-Proton 的 x86_64 驱动入口地址兼容处理，修正驱动服务名称与完整注册表路径的使用。
- 补充 MDL 内存映射生命周期：偏移地址、共享内容、多重引用和最后一次释放时的延迟解除映射。
- 查询真实的进程退出状态和用户线程上下文；线程所属进程接口改为默认构建。
- 构建并在复制的容器中配置上游最小 Wine `lsass.exe` 组件。它不是完整 Windows 安全服务。
- 将新增源码接入构建、运行时准备、安装和回归测试脚本。已有入口保留；升级需重新构建并安装到新目录。

原有 NOP 兼容、特权异常分类、背景视频回退及高清设置继续保留。`MmCopyMemory` 新增导出，但仍明确返回不支持；未支持的内核线程上下文也返回失败。

## 验证范围

更新后的测试会话中，用户报告游戏可玩，并完成过战斗和爬塔。后续回调实验曾造成卡死；该实验已撤回，不包含在本次源码中。恢复可玩配置后，用户再次确认大厅页面能正常切换，游戏日志记录大厅与塔入口间切换。

发布源码从该可玩基线提取，去除了临时诊断和内存快照代码。干净源码已编译成功，原生兼容测试和 Wine 接口测试通过。新安装流程中的配置写入另有独立验证，但尚未把这次干净构建从安装到战斗完整跑一遍。旧版本的十分钟验证不作为本次版本的持续游玩时长。

已知限制：两个后台 ACE CORE 驱动进程仍有异常退出记录。可玩不代表所有保护组件正常或官方支持；长期稳定性仍待验证。详细证据见 [验证记录](VALIDATION.md)。

## 发布内容

只发布源码、补丁、测试和中英双语文档。排除游戏/ACE 文件、CrossOver 二进制、容器、登录状态、日志、截图、内存快照和本机配置。上游作者与提交记录见 [来源说明](../THIRD_PARTY.md)。
