# 0.2.0 — NIKKE 152.8.11 compatibility update

Experimental source update for NIKKE PC Global 152.8.11, tested on Apple M4 Max, macOS 27.0 and CrossOver 26.1 with DXVK and the existing software-video fallback.

## Changes

- Adapt DW-Proton's x86_64 driver-entry address handling and separate the driver service name from its full registry path.
- Add MDL mapping lifetime handling for interior addresses, shared contents, multiple references and deferred unmapping after the last release.
- Query actual process exit status and user-thread context; include the thread-owner API by default.
- Build and configure the upstream minimal Wine `lsass.exe` component inside the copied bottle. It does not implement Windows security services.
- Integrate the additions into the build, runtime preparation, installation and regression scripts. Existing entries are preserved; upgrading requires rebuilding into new directories.

The NOP bridge, privileged-fault classification, video fallback and high-resolution setup remain available. The new `MmCopyMemory` export explicitly reports unsupported behavior, as does unsupported kernel-thread context retrieval.

## Validation scope

During updated-client testing, the user reported playability, combat and a tower run. Later callback experiments caused a freeze; those experiments were reverted and are excluded. After restoring the playable configuration, the user again confirmed responsive lobby navigation, supported by lobby/tower-entrance transitions in the game log.

Published source is extracted from that playable baseline without temporary diagnostics or memory-snapshot code. A clean build, native regressions and Wine API tests passed. Installation configuration has separate validation, but this exact clean build has not been exercised from fresh installation through combat. The old client's ten-minute result is not reused as a session-duration claim for this update.

Known limitation: two background ACE CORE driver processes still exit abnormally. Playability does not establish that all protection components are healthy or officially supported. Long-term stability remains unverified. See [Validation](VALIDATION.md).

## Distribution

Only source, patches, tests and bilingual documentation are published. Game/ACE files, CrossOver binaries, bottles, sign-in state, logs, screenshots, memory snapshots and local configuration are excluded. See [provenance](../THIRD_PARTY.md) for upstream authors and commits.
